# AI 开发入口

本目录是工作台跨 AI、跨开发工具协作的唯一文档入口。除根目录 `AGENTS.md` 因工具自动发现必须保留外，入口、稳定设计、动态交接和维护规范全部放在本目录，并纳入 Git 管理。

每份文档都受篇幅预算约束：要足以独立接手，又不得写成重复的流水账；具体区间与删改规则见 `协作与文档规范.md`。

## 开始前必须做

1. 阅读仓库根目录 [`AGENTS.md`](../../AGENTS.md)，遵守项目级安全、兼容、提交和部署规则。
2. 阅读本文件，随后按任务路由读取 [`评标工作台设计.md`](评标工作台设计.md) 的相关章节。
3. 阅读 [`AI_HANDOFF.md`](AI_HANDOFF.md)，但先用 `git status --short`、`git log`、测试和运行时版本核对其时效性。
4. 修改文档或移交任务时遵守 [`协作与文档规范.md`](协作与文档规范.md)。
5. 不从聊天摘要、旧报告或单次模型结果直接推断当前代码行为。

## 事实来源

| 信息 | 唯一事实来源 |
|---|---|
| 用户当前决定 | 当前用户明确指令 |
| 全仓库工程、安全、提交、部署约束 | 根目录 `AGENTS.md` |
| 工作台长期产品、架构、业务与验收基线 | `评标工作台设计.md` |
| 当前未完成工作和下一动作 | `AI_HANDOFF.md`，且必须与 Git/运行时核验 |
| 当前实现行为 | 代码与自动测试 |
| 修改历史、提交和回退点 | Git |
| 默认提示词 | `dashboard/evaluation_workbench/prompt_templates.py` |
| 云端自定义提示词、模型和通用规则 | 云端数据库及任务实际指纹 |
| 云端已运行版本 | build-info 与任务运行时版本，不能只看提交说明 |
| 密钥 | 仅运行环境；不得进入本目录、Git、日志或回复 |

发生冲突时，优先级为：用户当前明确决定 > `AGENTS.md` > 已核验的代码/测试/运行时事实 > 稳定设计基线 > 当前交接记录 > Git 历史说明。代码与稳定设计冲突时，不得任选一方；先查测试、运行数据和引入该差异的提交，再修正错误一侧。

## 不可越过的默认边界

- 修改必须通用、治本；禁止为某项目、投标人、文本、设备、金额、页码或年份打生产补丁。
- 禁止继续采用“发现一个错误，再加提示词、正则或展示兜底”的修补模式。
- 先定位最早出错层，再修改；模型负责语义，代码负责身份、结构、守恒、来源和状态。
- 不改变业务口径、默认工作流和既有 API，除非用户已明确确认。
- 不降低全文覆盖、规则/关键问题召回、证据可追溯性和失败隔离来换速度或 Token。
- 未经用户确认，不提交、不推送、不部署；不得记录或回显任何密钥。

## 结束前最小闭环

1. 说明不变契约和本轮改动层；补充能证明根因的通用测试。
2. 执行相关定向测试、工作台完整回归和 `git diff --check`。
3. 长期契约改变才更新设计；未完状态才更新交接；普通过程留在 Git。
4. 运行 `python docs/ai协作/validate_docs.py`。
5. 更新交接中的提交、工作树、测试、云端版本和下一动作；不确定的信息写“未知/待核验”，禁止猜测。
